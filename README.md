# نَشْرَة (Nashrah)

تطبيق ويب عربي (RTL) لتدوين اليوميات على هيئة جريدة أسبوعية كلاسيكية.

## هيكل الملفات
- `index.html`: الهيكل الرئيسي للتطبيق (غرفة التحرير + الجريدة الأسبوعية + الإعدادات).
- `css/style.css`: تعريف الخط المخصص (`@font-face`) وتنسيقات الجريدة وتصدير الصور.
- `js/app.js`: منطق التحديث التراكمي، التنقل بين الأعداد، الحفظ التلقائي في `localStorage`، تصدير الشعار الشفاف، وتصدير الجريدة كصورة.
- `assets/fonts/ArefRuqaa-Bold.ttf`: الخط المخصص لشعار "نَشْرَة".
- `assets/images/malam-logo.png`: شعار مَعْلَم في التذييل.

## التشغيل
افتح `index.html` مباشرة في المتصفح أو ارفع المجلد على GitHub Pages / أي استضافة ثابتة.
